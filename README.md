# CCNA-Enterprise-Cabling
Enterprise office network topology project using Cisco Packet Tracer, focused on CCNA  interfaces, cables, switches, router, firewall, and documentation.
# Enterprise Office Physical Network Infrastructure Design

## Project Overview
This project is a professional enterprise-style network topology built using Cisco Packet Tracer as part of my CCNA learning journey following Jeremy’s IT Lab Day 2 topic: Interfaces and Cables.

The project demonstrates:
- Physical network infrastructure design
- Cable selection
- Interface identification
- Enterprise topology architecture
- Layer 2 and Layer 3 networking concepts

---

# Enterprise Objective

A medium-sized company requires a scalable and structured office network to connect multiple departments, servers, printers, IP phones, and internet connectivity through centralized switching, routing, and firewall security.

---

# Network Architecture

Administration Department → SW-ADMIN  
Engineering Department → SW-ENG  
Management Department → SW-MGMT  

SW-ADMIN ↘  
SW-ENG → CORE-SW → EDGE-RTR → ASA Firewall → Internet  
SW-MGMT ↗
